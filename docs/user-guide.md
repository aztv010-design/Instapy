# User Guide

## Getting Started

### 1. Login

Visit `http://localhost:9003` and login with your credentials.

### 2. Create New Scan

1. Click "Profile Analysis" in the sidebar
2. Enter Instagram username
3. Click "Analyze Profile"
4. Wait for results

## Features

### Profile Analysis

Get detailed information about Instagram accounts:
- Username, full name, bio
- Follower/following count
- Profile picture
- Verification status
- Account age

### Fake Account Detection

Identify suspicious accounts using AI:
- Follower ratio analysis
- Activity pattern detection
- Engagement metrics
- Account behavior

### Network Analysis

Visualize connections between accounts:
- Follower networks
- Engagement patterns
- Account clusters
- Relationship graphs

### Reports

Generate comprehensive reports:
- PDF format
- Excel export
- JSON data
- Timeline analysis

## Best Practices

1. **Verify Results** - Always verify findings independently
2. **Use Responsibly** - Respect privacy and laws
3. **Save Backups** - Keep copies of important reports
4. **Update Regularly** - Keep the application updated

## Keyboard Shortcuts

- `Ctrl+K` - Search
- `Ctrl+S` - Save report
- `Ctrl+E` - Export data

## FAQ

**Q: Why is the scan slow?**
A: Large profiles with many followers take longer to analyze.

**Q: Can I export data?**
A: Yes, reports can be exported as PDF or Excel.

**Q: How accurate is the fake detection?**
A: ~95% accuracy based on multiple factors.

**Q: Can I delete my data?**
A: Yes, go to Settings > Privacy > Delete Data.
